# Softec Vision — קטלוג עמדות מרצה ובקרה

אתר קטלוג מוצרים של **Softec Vision Ltd** — עמדות מרצה, עמדות בקרה ותצוגה אינטראקטיבית.

אתר סטטי בקובץ אחד (`index.html`) — כל התמונות, ה-CSS וה-JS מוטמעים בפנים. אין שלב build ואין תלויות.

## 🌐 פריסה (GitHub Pages)

1. העלה את `index.html` לשורש (root) של ה-repo.
2. **Settings → Pages → Source: Deploy from a branch → `main` / `root` → Save**.
3. האתר יעלה בכתובת: `https://ward3107.github.io/softec-vision/`

כל push ל-`main` מעדכן את האתר אוטומטית.

### דומיין מותאם (אופציונלי)
Settings → Pages → Custom domain — הכנס דומיין, וב-DNS של הדומיין הוסף רשומת CNAME ל-`ward3107.github.io`.

## ✏️ איך לעדכן

הכל בקובץ `index.html`.

### מספר הוואטסאפ
חפש את השורה:
```js
const WA_NUMBER = '972544742520';
```
פורמט בינלאומי, בלי `+` ובלי מקפים. זה המספר שאליו נשלחת הודעת "רוצה את המוצר".

### מוצרים
חפש את המערך `const products = [`. כל מוצר:
```js
{ code:'V-19W', name:'שם המוצר', img:'data:image/jpeg;base64,...',
  desc:'תיאור קצר של המוצר.' },
```
- `code` — קוד הדגם (מופיע קטן מעל השם)
- `name` — שם המוצר
- `desc` — התיאור שמופיע בצד האחורי של הכרטיס ובתצוגה המוגדלת
- `img` — התמונה כ-base64 (ראה למטה איך מחליפים)

### החלפת תמונה
ממירים תמונה ל-base64 ומדביקים במקום ה-`img`. למשל בטרמינל:
```bash
echo "data:image/jpeg;base64,$(base64 -w0 photo.jpg)"
```
(מומלץ להקטין תמונות ל-~900px רוחב ואיכות ~75% לפני ההמרה, כדי לשמור על קובץ קליל.)

### טקסטים כלליים
כותרות, "אודות", מפרט ותהליך — כתובים ישירות ב-HTML, קל לחפש ולערוך.

## 🗂️ קטגוריות ותת-קטגוריות

הקטלוג מסונן לפי קטגוריות. מעל רשת המוצרים יש **סרגל קטגוריות**; בחירת קטגוריה שיש
לה תת-קטגוריות פותחת **סרגל תת-קטגוריות** נוסף. עץ הקטגוריות מוגדר במערך `CATEGORIES`
ב-JS, וכל מוצר משויך בעזרת שני שדות במערך `products`:

```js
{ code:'V-19W', name:'...', cat:'podium', sub:'smart', img:'...', ... }
```

- `cat` — מפתח הקטגוריה (מ-`CATEGORIES`)
- `sub` — מפתח תת-הקטגוריה (ריק `''` אם לקטגוריה אין תת-קטגוריות)

עץ הקטגוריות הנוכחי:

| קטגוריה (`cat`) | שם תצוגה | תת-קטגוריות (`sub`) |
|---|---|---|
| `podium` | עמדות מרצה – פודיום | `no-tech` (ללא טכנולוגיה), `smart` (חכמות), `double` (כפולות), `audience-screen` (מסך לכיוון הקהל), `accessible` (נגישות), `tables` (שולחנות מרצה) |
| `info-display` | עמדות מידע ותצוגה | — |
| `control` | שולחנות בקרה ושליטה | `control-desks` (שולחנות בקרה), `operator` (עמדות מפעיל) |
| `charging-carts` | עגלות טעינה למחשבים | — · **מוסתר בעברית, נסרק בגוגל** (ראה למטה) |
| `service-carts` | עגלות מחשוב ושירות | — |
| `custom` | תכנון וייצור פתרונות קאסטום | — |

קטגוריה שאין בה עדיין דגמים מציגה קריאה ל"הזמנה מותאמת" עם קישור ליצירת קשר, כך שכל
ענף בעץ גלוי וניתן לגלישה. להוספת קטגוריה/תת-קטגוריה — הוסף איבר ל-`CATEGORIES`.

### עגלות טעינה למחשבים — מוסתר בעברית, נסרק בגוגל
לפי הדרישה, `charging-carts` **לא** מופיע כצ'יפ בסרגל הקטגוריות בעברית, אך התוכן שלו
(כותרת ותיאור באנגלית + עברית) יושב בבלוק `.seo-only` (id `seo-charging-carts`) בתוך
מקטע `#products`. הבלוק מוסתר חזותית (`clip`, **לא** `display:none`) כדי שיישאר ב-DOM
וייסרק/יאונדקס ע"י מנועי חיפוש. כשתיווסף תמיכה רב-לשונית, אפשר יהיה להציג את הקטגוריה
בגרסה האנגלית בלבד.

## 🎨 עיצוב
- רקע לבן, מינימליסטי בסגנון iOS, פינות מעוגלות ואנימציות scroll.
- צבע מותג: תכלת (`--sky: #3AA7F0`) — ניתן לשינוי במשתני ה-`:root` בראש ה-CSS.
- צילומי המוצרים מוצגים בשחור-לבן (פילטר `grayscale`) לאחידות.

## 🖼️ תמונות מרובות זווית (גלריה)

כברירת מחדל לכל מוצר יש תמונה אחת. להוספת זוויות נוספות, הוסף שדה `imgs` למוצר במערך `products`:
```js
{ code:'V-19W', name:'...', img:'תמונה-ראשית-base64',
  imgs:['זווית1-base64','זווית2-base64','זווית3-base64'],
  desc:'...' }
```
בתצוגה המוגדלת (lightbox) יופיעו אוטומטית תמונות ממוזערות (thumbnails) וחיצי ניווט. אם יש תמונה אחת בלבד — לא מופיעים.

## 🧊 תצוגת תלת-ממד (3D)

להצגת כפתור "תצוגת 3D" למוצר, הוסף שדה `model3d` עם קישור לקובץ `.glb`:
```js
{ code:'V-19W', name:'...', img:'...', model3d:'models/v19w.glb', desc:'...' }
```
- העלה את קובץ ה-`.glb` ל-repo (למשל בתיקייה `models/`).
- הכפתור "תצוגת 3D" יופיע בתצוגה המוגדלת רק למוצרים שיש להם `model3d`.
- המשתמש יכול לגרור לסיבוב המודל.
- הסקאן עצמו (photogrammetry / 3D scan) → ייצוא ל-`.glb` → העלאה. מומלץ לדחוס עם [gltf-transform](https://gltf-transform.dev/) כדי לשמור על קובץ קליל.

טיפ: לביצועים טובים בנייד, כוון את המודל ל-~2-5MB ופוליגונים סבירים.

## 📋 מפרט טכני (Spec) והשוואת דגמים

לכל מוצר יש שדה `specs` — אובייקט של מאפיין→ערך. הוא מזין גם את **טבלת המפרט** בתצוגה המוגדלת וגם את **השוואת הדגמים**:
```js
specs:{
  'מסכים':'2 רחבים + 2 עזר',
  'גימור':'פח צבוע דו-גוני',
  'מידות (ג×ר×ע)':'[למילוי]',
  'משקל':'[למילוי]',
  'חשמל':'[למילוי]',
  'ניהול כבלים':'סמוי מלא'
}
```
- ערכים עם `[למילוי]` מוצגים באפור נטוי — **על Softec להשלים** מידות/משקל/חשמל אמיתיים לפני פרסום.
- אפשר להוסיף/להסיר מאפיינים בחופשיות; ההשוואה מאחדת אוטומטית את כל המאפיינים של הדגמים הנבחרים.

**השוואה:** המשתמש מסמן "השוואה" על 2–3 כרטיסים → נפתחת מגירה תחתונה → כפתור "השוואה" פותח טבלה זו-לצד-זו.
